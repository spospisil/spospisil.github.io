# Steve Pospisil - Professional Portfolio

A mobile-first GitHub Pages site presenting software engineering experience, technical expertise, and responsive web design capabilities.

## Features

- Professional overview and career highlights
- Three responsive interface concepts covering commerce, professional services, and product design
- Mobile navigation with keyboard and reduced-motion support
- Fluid layouts tested across phone, tablet, and desktop widths
- Lightweight implementation using semantic HTML, CSS, and JavaScript

## Local Preview

Open `index.html` directly in a browser. No build step or local server is required.
